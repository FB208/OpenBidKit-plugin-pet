# 易标桌宠

易标投标工具箱的动画悬浮桌宠插件。插件通过平滑的状态动画实时展示主程序当前任务名称、进度和完成状态，并可快捷回答 Agent 发起的确认问题。

## 功能

- 透明、置顶、可拖动的动画桌宠
- 任务状态使用独立宽气泡展示，不受角色窗口宽度约束，并自动跟随角色位置
- 待命与五组巡边动作均使用 24 张真实帧，其余状态使用 16 张真实帧，不使用透明叠帧
- 统一角色体量、视觉中心和脚底基线
- 启动问候动画保持独立，待命时每 5 秒自然眨眼一次
- 持续待命 10 秒后开始播放已开启的待机效果；每种效果连续播放 10 分钟，再切换到下一种
- 鼠标悬浮角色时播放一次完整待机互动，角色本体可直接拖动
- 使用最高桌面悬浮层级，稳定显示在普通置顶窗口上方
- 实时显示易标当前任务状态；正文生成时同时展示累计进度、当前阶段和阶段进度
- Agent 需要确认时，在桌宠旁显示可交互问答气泡；普通选项一键回答，自定义选项可直接填写具体要求
- 主程序确认弹窗与桌宠问答气泡保持同步，任一处回答后另一处自动关闭
- 记住上次窗口位置
- 配置页可切换完整动作皮肤，并按效果独立开关附加动画；保存后即时应用
- 禁用插件或关闭主程序时自动清理窗口和订阅

## 皮肤设置

配置页会按皮肤注册表展示可即时切换的完整动作皮肤。当前提供：

- **经典小易**：易标默认的蓝色软胶小易形象。
- **圣剑歌手**：黑发黑衣、手持紫色麦克风的毛绒小歌手。

全部皮肤共用 8 列、36 行图集，并提供下方列出的 15 组同语义动作。

## 效果设置

配置页的“效果开启”区域会按注册表展示可独立启停的附加动画。当前提供：

- **瞎溜达**：默认开启。以每秒 40 像素的舒缓速度走向最近竖边，并按“左侧向上、顶部向右、右侧向下、底部向左”沿多屏桌面顺时针巡边。
- **睡觉**：默认开启。角色闭眼安静入睡，以低干扰的呼吸和轻微身体起伏表现睡眠节奏。

多个效果同时开启时按注册顺序轮换，每种保持 10 分钟；只有一个效果开启时会持续保持该效果。任务、拖动或鼠标悬浮会立即中断，重新待命后从中断的效果重新计算完整 10 秒启动时间和 10 分钟播放时段。

## 动画与触发条件

精灵图共包含 15 组动作，其中待命动作会被复用为静止、眨眼和鼠标悬浮互动三种运行效果。

| 动画 | 帧数与速度 | 触发条件 | 播放方式 |
| --- | --- | --- | --- |
| 待命静止（`idle-rest`） | 待命组首帧 | 当前没有任务，且启动问候、拖动或互动动画已经结束 | 保持静止，避免桌宠持续晃动 |
| 自然眨眼（`blink`） | 6 帧，85 毫秒/帧 | 待命静止满 5 秒、没有拖动，且鼠标未悬浮在角色上 | 单次播放；结束后重新开始 5 秒计时 |
| 悬浮互动（`idle-hover`） | 24 帧，160 毫秒/帧 | 待命状态下鼠标进入角色，或进入待命时鼠标已经停在角色上 | 单次播放；持续悬浮不会循环，移出再移入可再次触发 |
| 启动问候（`waving`） | 16 帧，70 毫秒/帧 | 插件启用后首次进入待命状态 | 仅播放一次；如果启用时正在执行任务，会延迟到首次待命时播放 |
| 向右移动（`running-right`） | 16 帧，60 毫秒/帧 | 拖动窗口并产生向右的水平位移 | 移动期间循环播放，停止移动约 140 毫秒后恢复最新状态动画 |
| 向左移动（`running-left`） | 16 帧，60 毫秒/帧 | 拖动窗口并产生向左的水平位移 | 移动期间循环播放，停止移动约 140 毫秒后恢复最新状态动画 |
| 向右走路（`walking-right`） | 24 帧，120 毫秒/帧 | 十秒待命结束后，当前位置更靠近右侧屏幕边缘 | 左右脚交替循环，直到抵达右侧边缘 |
| 向左走路（`walking-left`） | 24 帧，120 毫秒/帧 | 十秒待命结束后走向左侧边缘，或沿屏幕底部向左移动 | 左右脚交替循环，直到停止移动 |
| 向上攀爬（`climbing-up`） | 24 帧，110 毫秒/帧 | 顺时针巡边经过屏幕左侧 | 双手空出并交替抓握，话筒固定胸前，直到抵达左上角 |
| 向下攀爬（`climbing-down`） | 24 帧，110 毫秒/帧 | 顺时针巡边经过屏幕右侧 | 双手空出并交替抓握，话筒固定胸前，直到抵达右下角 |
| 向右悬吊（`hanging-right`） | 24 帧，120 毫秒/帧 | 顺时针巡边经过屏幕顶部 | 双手交替悬吊前进，直到抵达右上角 |
| 睡觉（`sleeping`） | 16 帧，260 毫秒/帧 | 待机效果轮换到“睡觉” | 循环播放 10 分钟；角色以闭眼、呼吸和轻微起伏保持低干扰睡眠 |
| 任务执行（`running`） | 16 帧，60 毫秒/帧 | 当前任务处于执行中 | 循环播放，直到任务状态改变 |
| 等待处理（`waiting`） | 16 帧，80 毫秒/帧 | 当前任务正在暂停或已经暂停 | 循环播放，直到状态改变或暂停状态展示结束 |
| 完成跳跃（`jumping`） | 16 帧，65 毫秒/帧 | 当前任务执行成功 | 单次播放，随后自动进入检查动画 |
| 完成检查（`review`） | 16 帧，80 毫秒/帧 | 完成跳跃播放结束，且任务仍保持成功状态 | 循环播放，直到状态改变 |
| 执行失败（`failed`） | 16 帧，90 毫秒/帧 | 当前任务执行失败 | 循环播放，直到错误状态展示结束或状态改变 |

动画切换遵循以下规则：

- 窗口移动动画优先于其他动画；停止移动后按最新任务状态恢复。
- 任务状态动画优先于待命眨眼和鼠标悬浮互动。
- Agent 等待回答时临时使用等待动画并隐藏任务状态气泡，回答后恢复最新任务状态。
- 待机效果只在持续待命且鼠标未悬浮、没有拖动时启动；任务状态变化或用户交互会立即停止当前效果。
- 每个效果都可独立关闭；全部关闭时不会建立待机效果倒计时。
- 待机效果被中断后，重新进入待命会完整等待 10 秒，并从被中断的效果重新开始 10 分钟时段。
- 鼠标悬浮互动只会在待命状态触发，不会打断执行、等待、成功或失败动画。
- 没有其他活动任务时，成功和暂停状态各展示约 3 秒，失败状态展示约 5 秒，随后回到待命状态。

## 本地打包

```powershell
npm run package
```

打包结果位于 `dist/openbidkit-pet-v1.2.3.zip`。

也可以指定要写入发布包清单的版本：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\package.ps1 -Version 1.2.3
```

## 发布新版本

发布版本使用 `vX.Y.Z` 格式的 Git Tag。Tag 推送到 GitHub 后，Actions 会自动：

1. 校验 Tag 版本格式。
2. 将版本号和 Release 下载地址写入发布包内的 `manifest.json`。
3. 生成 `openbidkit-pet-vX.Y.Z.zip`。
4. 创建同名正式 Release 并上传 ZIP。

```powershell
git tag v0.2.0
git push origin v0.2.0
```

仓库工作区中的 `manifest.json` 不会被工作流回写，安装包内的版本信息以 Tag 为准。

## 本地部署

请先在易标插件管理页禁用旧版本，然后执行：

```powershell
npm run deploy:local
```

插件会部署到 `%APPDATA%\yibiao-client\plugins\openbidkit-pet`。
